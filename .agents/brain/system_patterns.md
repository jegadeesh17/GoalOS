# 🏛️ GoalOS System Patterns & Architectural Invariants

This document establishes the unbreakable design patterns, code idioms, data structures, and architectural standards enforced across the GoalOS repository.

---

## 1. 🐍 Backend & Python Architectural Invariants

### 1.1 Layer Separation & Dependency Rule
Dependencies strictly flow inwards:
$$\text{API Layer (FastAPI)} \longrightarrow \text{Service Layer} \longrightarrow \text{Repository Layer} \longrightarrow \text{Database (SQLite/Chroma)}$$
- **Rule:** API routes in `api/main.py` MUST NOT execute raw SQL queries. All persistence logic belongs in `database/repositories/*`.
- **Rule:** Models in `models/*` are pure Pydantic v2 schemas used for validation and serialization.
- **Rule:** AI logic and prompt generation belong in `ai/pipelines/*` or `ai/tools.py`.

### 1.2 Database Connections & Transactions
- **Context Manager Invariant:** Always access SQLite via `with get_db() as conn:`.
- **Row Factory:** Connections use `sqlite3.Row` for dictionary-like column access.
- **Migrations:** Never write non-transactional DDL in application code. All schema modifications must be registered in `database/migrations.py` with an incremental migration version.

### 1.3 Memory Dual-Write Pattern
- Every call to `MemoryService.store()` must:
  1. Calculate normalized SHA-256 content hash: `hashlib.sha256(" ".join(text.casefold().split()).encode("utf-8")).hexdigest()`.
  2. Perform SQLite upsert in table `memories`.
  3. Upsert FTS5 full-text index in `memory_fts`.
  4. Attempt ChromaDB vector indexing. If ChromaDB is temporarily unavailable or locked, set `index_status = 'pending'` and continue gracefully.

### 1.4 API Safety & Request Guards
- Every endpoint receiving user payload must enforce Pydantic validation.
- Request bodies are capped at 512KB via `limit_request_body` middleware.
- In production, bearer tokens are verified in constant time via `hmac.compare_digest`.

## 2. ⚛️ Frontend & React Architectural Invariants

### 2.1 Celestial Light Design System Tokens
- **Theme Palette:**
  - Background: `bg-[#f8faff]` (Soft celestial canvas)
  - Surface Cards: `bg-white/80 backdrop-blur-md border border-indigo-50/60 shadow-sm rounded-2xl`
  - Primary Accent: `text-indigo-600`, `bg-indigo-600 hover:bg-indigo-700 text-white`
  - Secondary Accent: `text-purple-600`, `bg-purple-50 border border-purple-100`
  - Success/Pacing: `text-emerald-600`, `bg-emerald-50 border border-emerald-100`
  - Warning/Fatigue: `text-amber-600`, `bg-amber-50 border border-amber-100`

### 2.2 Typography Scale & Non-Redundancy
- **H1 Header:** `text-2xl font-bold tracking-tight text-slate-900`
- **H2 Header:** `text-xl font-bold text-slate-800`
- **H3 Header:** `text-sm font-bold text-slate-700`
- **Metrics Display:** `text-xl font-bold tracking-tight`
- **Body Text:** `text-sm font-normal text-slate-600`
- **Labels / Badges:** `text-xs font-medium uppercase tracking-wider`
- **Single Source of Truth:** Never render duplicate metric summaries on the same screen (e.g. Life Calendar week count is rendered once in the header banner, not repeated in inner views).

### 2.3 State Management & API Client
- All HTTP calls must use `frontend/src/api/client.ts`.
- Optimistic UI updates must be backed by error rollback notifications.
- All forms must handle loading, success, and offline error states cleanly.

## 3. 🤖 AI Coaching & Hybrid RAG Invariants

### 3.1 5-Factor Retrieval Formula
Retrieval composite score MUST adhere to:
$$S = 0.35 \cdot S_{\text{sem}} + 0.15 \cdot S_{\text{lex}} + 0.25 \cdot S_{\text{imp}} + 0.15 \cdot S_{\text{rec}} + 0.10 \cdot S_{\text{freq}}$$
- Lexical match boost is capped at $1.0$.
- Recency uses a 30-day half-life decay function: $\exp(-0.693 \cdot \Delta t / 30)$.
- Frequency uses logarithmic scaling: $\min(1.0, \ln(1 + n) / \ln(100))$.
- MMR similarity filtering rejects any candidate with cosine similarity $> 0.94$ against previously chosen items.

### 3.2 Deterministic Fallback Invariant
- Remote LLMs are never assumed to be available.
- If `remote_ai_consent == False`, or `OPENROUTER_API_KEY` is empty, or network fails:
  - The system MUST return structured deterministic coaching generated by local rule engines (`services/coach_service.py`).
  - The output must include `fallback_reason` and `source = 'deterministic_rules'`.

## 4. 🌿 Git Discipline & Repository Patterns

### 4.1 Commit Granularity & Types
- Atomic Conventional Commits (`feat`, `fix`, `docs`, `refactor`, `perf`, `test`, `chore`).
- Format: `<type>(<scope>): <summary>`.
- Scope reflects the domain (`memory`, `api`, `coach`, `calendar`, `brain`, `rules`, `analytics`).

### 4.2 Pre-Commit Verification
- Run `git status --short` to inspect modified and untracked files before staging.
- Never commit secrets (`.env`), unneeded binary caches, or temporary scripts.
- Never force-push or reset without explicit confirmation.
